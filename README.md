# ❤️ Love Page

Нежное веб-приложение для двоих — личное пространство пары с календарём отношений, фотоальбомом и счётчиком дней вместе.

## ✨ Возможности

- 🔐 **Авторизация** — вход и регистрация по email/паролю
- 💞 **Привязка пары** — создать уникальный pair-код или подключиться по коду партнёра
- 🏠 **Главный экран** — аватары обоих партнёров, статус «мы вместе» и счётчик дней, месяцев и лет
- 📅 **Календарь отношений** — отметки важных событий по дням, навигация по месяцам и годам
- 📸 **Фотоальбом** — загрузка и хранение совместных моментов, привязанных к датам
- ⚙️ **Профиль пары** — настройка имён, аватарок и даты знакомства
- 💔 **Управление связью** — возможность разорвать пару или выйти из аккаунта

## 🛠 Стек

## 🚀 Запуск локально

Это статический одностраничный сайт — открывается в браузере без сборки.

```bash
# 1. Клонировать
git clone https://github.com/Hii1111/love-page.git

# 2. Перейти в папку
cd love-page

# 3. Открыть index.html в браузере
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

Или просто задеплоить на любой статический хостинг: **GitHub Pages**, **Vercel**, **Netlify**, **Cloudflare Pages**.

## ⚙️ Настройка Supabase

1. Создай проект на [supabase.com](https://supabase.com)
2. Включи **Auth** (email/пароль)
3. Создай таблицы для пар, событий и фото
5. Заполни в `index.html` свои `SUPABASE_URL` и `SUPABASE_KEY`

> 🔒 **Важно:** ключи Supabase не должны попадать в публичный репозиторий. Для production рекомендуется вынести их в переменные окружения или приватный конфиг.
